⚙️ AI 寫作風格設定

填入文章資訊，點「複製完整提示詞」，貼到 Claude / ChatGPT / Gemini 即可生成文章。

這篇文章的核心知識點、重要數字或切入觀點，AI 會以這些為基礎撰寫。可用「✨ 幫我發想」按鈕自動生成。

選擇一篇文章作為風格參考，AI 會以該文章的觀點深度、段落銜接和核心論點展開邏輯為基準，不會複製內容。

📌 預設參考文章

設定後，每次新開後台預設選取這篇文章作為風格參考。

🔄 產生 articles-index.json

第一次使用時執行，從現有 articles.json 產生輕量索引檔案，供前台讀取使用。

🔄 重新產生所有文章

還原備份後、更新模板設計後、或更換網域後，點此一鍵重新產生所有文章 HTML 並更新 sitemap。

🧹 孤兒 HTML 清理

掃描 articles/ 資料夾，找出不在文章清單內的舊版或廢棄 HTML 檔案，可以一次刪除。不會影響正式文章。

💾 資料備份

建議定期將文章資料備份到你的電腦，以防萬一。下載的 JSON 檔案可以在需要時重新上傳到 GitHub 還原。

    {"q": "問題一", "a": "回答一"},
    {"q": "問題二", "a": "回答二"}
